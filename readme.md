# Uso

```bash
python trabalho.py <arquivo_de_entrada.txt>
```

Descrição

O programa realiza a simulação da redistribuição populacional em uma malha aérea com base em um sistema de equações lineares resolvido pelo método de Gauss-Seidel.
Saída

O programa exibirá, nesta ordem:

- O sistema de equações montado.

- A prova real (validação das equações).

- As populações finais dos aeroportos.(Para não deixar muita infornação, só os 10 primeiros)

- O aeroporto com menor e maior população.
